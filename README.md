# Power-BI-project_Tailwind-Traders
This is a sample Power BI Capstone project within the scope of "Deploy and Maintain Power BI Assets and Capstone project" course of "Microsoft Power BI Data Analyst" Professional certificate on Coursera platform.

## Purpose & Scope

Purpose of this project is to enhance learning through implementation in below aspects,

- Data preparation in Excel
- Load data to Power BI Desktop and configure data types
- Check data validity through column properties
- Design and develop the data model (in STAR Schema)
- Create tables and measures via DAX (Data Analytics Expressions)
- Create visuals (bar, line, area, pie, donut charts, KPI cards) and reports
- Create an executive dashboard
- Generate alerts and configure subscriptions
